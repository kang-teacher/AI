# AI 개념 교실

정보 교과 인공지능 수업용 웹사이트예요. 학생들이 개념을 직접 누르고, 끌고, 학습시키며 이해하도록 만들었어요.
[YOLO 객체인식 교실](https://kang-teacher.github.io/YOLO/)의 디자인과 일부 활동을 가져와 다시 다듬었어요.

## 단원 구성

| 단원 | 마당 | 주요 활동 |
| --- | --- | --- |
| 1. 인공지능의 개념 | 1-1 AI·ML·DL · 1-2 인공지능의 특성 · 1-3 규칙 vs 학습 | 포함 관계 원, 특성 6가지 카드와 작은 체험, 규칙 직접 짜기, 퍼셉트론 학습 |
| 2. 탐색 | 2-1 상태와 상태 공간 · 2-2 강 건너기 만들기 · 2-3 맹목적 탐색 · 2-4 정보 이용 탐색 · 2-5 8-퍼즐 | 강 건너기와 상태 공간 지도, 나만의 강 건너기 문제 풀이기, 깊이·너비 우선 단계 보기, 미로 탐색 경주(DFS·BFS·최상 우선·A*), 8-퍼즐 풀기·만들기·탐색 비교 |
| 3. 데이터 다루기 | 3-0 문제 해결 과정 ~ 3-7 시각화·핵심 속성 (8개) | 5단계 순서 맞히기, 수집 방법 체험과 우리 반 설문, 정형화(그림·글·소리 → 숫자), 속성 종류 맞히기, 편향 실험과 오버/언더 샘플링, 결측치·이상치 탐정, 스케일링·인코딩, 그래프 4종·상관계수·핵심 속성 고르기 |
| 4. 머신러닝의 유형 | 4-0 한눈에 보기 ~ 4-7 정리 (8개) | 레이블 달기, 선형 회귀(단순·다중), K-NN, 결정 트리, 훈련/테스트 분할, 오차·혼동행렬·정밀도·재현율·F1, 과대/과소적합, K-평균·엘보우, 장바구니 분석, 강화학습(보물 찾기, Q-러닝 미로, 슬롯머신과 탐험·활용) |
| 5. 딥러닝 | 5-1 퍼셉트론 · 5-2 인공신경망 · 5-3 딥러닝의 활용 | 생체 신경 vs 인공신경, 소풍 퍼셉트론, AND·OR·XOR 학습, 신경망 신호 흐름, 은닉층으로 XOR 풀기, 컴퓨터 비전·음성 인식·언어 모델·멜로디 만들기 |

각 마당 끝에는 확인 퀴즈가 있어요. 진도와 퀴즈 결과는 브라우저(localStorage)에만 저장돼요.

## 실행과 배포

- 빌드 과정이 없는 HTML/CSS/JS 사이트라서 `index.html`을 브라우저로 열면 바로 동작해요.
- GitHub Pages: 저장소 **Settings → Pages**에서 `main` 브랜치의 `/ (root)`를 고르면 `https://kang-teacher.github.io/AI/`로 열려요.

## 파일

- `index.html`: 모든 단원 화면
- `css/style.css`: YOLO 사이트와 같은 기본 디자인, `css/ai.css`: 이 사이트에 새로 쓴 디자인
- `js/common.js`, `js/util.js`: 공통 도우미, `js/main.js`: 페이지 이동·진도·첫 화면
- `js/u1.js` ~ `js/u5.js`: 단원별 활동, `js/quiz.js`: 확인 퀴즈, `js/scene.js`: 컴퓨터 비전 예시 그림
